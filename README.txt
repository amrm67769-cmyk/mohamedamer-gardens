# موقع مهندس محمد عامر لتنسيق وتصميم الحدائق والفلل

هذه نسخة ويب جاهزة للنشر (Static Website).

## قبل النشر
1. افتح `script.js`.
2. استبدل `PUT_YOUR_NUMBER_HERE` برقم واتساب بصيغة دولية بدون علامة + أو مسافات.
3. في `index.html` عدّل نص "أضف رقمك هنا" و"أضف بريدك هنا" إلى بيانات التواصل الحقيقية.
4. استبدل صور المعرض بصور أعمالك الحقيقية إذا أردت.

## النشر
يمكن رفع الملفات الثلاثة (`index.html`, `styles.css`, `script.js`) على أي استضافة مواقع ثابتة مثل GitHub Pages أو Netlify أو أي استضافة تدعم HTML.

## الظهور في Google
بعد نشر الموقع على نطاق حقيقي:
- أضف الموقع إلى Google Search Console.
- اطلب فهرسة الصفحة الرئيسية.
- أضف بيانات نشاطك التجاري الحقيقية إلى الموقع.
- أنشئ/حدّث ملف Google Business Profile إن كان لديك نشاط مؤهل.

ملاحظة: الموقع نفسه لا يحتاج إلى خادم أو قاعدة بيانات.
